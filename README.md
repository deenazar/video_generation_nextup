# video_generation_nextup

NextUp Learn reel generator (HyperFrames). Read `CLAUDE.md` first: it holds the workflow rules and how to build a reel.

- `template/` — starter project: avatar, fonts, NextUp logo, real brand logos, generator tools
- `examples/ai_layoffs/` — a finished reel's generator, photos and credits
- `reels/<topic>/` — one folder per new reel
