# Nex @nextup video repo

Read these before doing anything; they are the source of truth:

- `common/rules.md`: rules, conditions and defaults (one question, folder naming, one PR per job)
- `common/procedure.md`: step-by-step from pasted script to PR
- `common/skills/`: skills (`nex-reel-hyperframes` is the current standard)

## Layout

```
audio/      inbox: user drops the new MP3 here
common/     everything shared: rules, procedure, skills, templates, scripts, assets
videos/     one folder per video: <topic>_<contenttype>_<datetime>/ (script, voice.mp3, project, final.mp4)
```
